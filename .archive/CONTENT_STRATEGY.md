## 0. 架构创新:模块化内容生产线

### 0.1 核心设计理念
系统现已支持**多套完全独立的"内容配方"**,每套配方(模块)有自己的:
- 选题策略(财经数据 vs 娱乐八卦 vs 视频提取)
- 作者人设(财经观察机构 vs 娱乐评论员)
- 内容结构(数据解读型 vs 情绪共鸣型)
- 新闻来源(AKShare+搜狗 vs 微博热搜)
- 发布频率(每天1篇 vs 每天3篇)

但底层**公共能力复用**:LLM/发布/审核/数据库/封面/导读。

### 0.2 技术架构
```
app/modules/
  ├── base.py           # BaseContentModule 抽象基类
  ├── registry.py       # 模块注册表
  └── finance/          # 财经模块(已实现)
      ├── config.py     # 配置(频率/字数/选题策略等)
      ├── writer.py     # 数据解读型 writer
      └── module.py     # FinanceModule 完整实现

未来扩展:
  └── entertainment/    # 娱乐模块(待实现)
  └── video/            # 视频模块(待实现)
```

### 0.3 扩展性
新增模块只需:
1. 继承 `BaseContentModule`,实现接口
2. 在 `registry.py` 注册
3. 配置调度器任务

不需改动现有代码,各模块完全隔离。

## 1. 问题诊断

### 1.1 根本原因
微信后台提示"低创作度内容",核心病因:
- **内容模式**: 复述单条新闻(新华社/央视/东方财富),信息增量≈0
- **AIGC 指纹**: writer 生成 → humanizer 再洗 → 双 LLM 叠加 AI 特征
- **机器标识**: 每篇结尾自动添加"(全文共 729 字)"
- **结构同质**: 195 篇已发文章都是"据 X 报道 + 数据堆砌 + 官腔评论"
- **prompt 缺陷**: 硬性要求"新闻事实占 3/4",等于主动制造高相似度

### 1.2 典型文章画像(id=319 电车国标为例)
```
开头: 据新华网、中国网报道,7月1日起…
中间: 大段复述官方数据、专家原话(韩广帅/吴凯/协会数据)
结尾: "从市场逻辑看…这笔成本必须付"+ (全文共729字)
```
**判定**: 全网已有信息的换说法复述,无独家增量。

## 2. 战略方向(已确认)

### 2.1 定位
- **数据驱动护城河**: 积累结构化财经数据,做"机器搬运不到"的数据解读
- **垂直聚焦财经**: 宏观经济、产业、资本市场、消费与就业
- **精品路线**: 每天 1 篇深度,质量>数量

### 2.2 核心策略
1. **从"复述新闻"到"数据解读"**: 不做新闻搬运工,做数据翻译官
2. **建立数据资产**: 本地积累历史数据,形成"时间序列对比/横向对比/趋势推演"能力
3. **签名结构**: 固定的"钩子→数据→解读→影响→判断"框架,让同题也难复刻
4. **去 AI 指纹**: 单次生成、去机器标识、打散同质结构

#### B. 提升推荐量的杠杆
1. **标题策略**: 
   - 带具体数字(5 月新能源车销量占比 56.9%,意味着什么)
   - 制造反差(A 涨 B 跌背后的逻辑)
   - 12-20 字,信息量足,不夸张
2. **开头 3 秒钩子**:
   - 第一句给结论或反常识判断
   - 第一段≤50 字,直接点出"这和读者钱包/生计的关系"
3. **完读率优化**:
   - 全文 650-750 字,手机 2-3 分钟读完
   - 每段 1-3 句,偶尔 1 句独立成段制造节奏
   - 插入数据图表(提升停留时长)
4. **互动信号**:
   - 结尾留判断或反问(不要求转发点赞,但引发思考)
   - 开启评论精选(引导留言讨论)
5. **原创声明**: 每篇申请原创保护,积累信用分
6. **发布时段**: 早 7-8 点(通勤)/ 午 12-13 点(午休)/ 晚 20-21 点(晚饭后)

#### C. 可量化质量指标
- 完读率 ≥ 50%(行业中位数约 30-40%)
- 在看率 ≥ 2%(阅读 1000,在看≥20)
- 收藏+转发率 ≥ 1%
- 评论率 ≥ 0.5%
- 原创违规率 = 0

### 3.3 财经内容主编 — 选题与模板

#### A. 选题策略(每天 1 篇)
**优先选题类型**(适合数据驱动):
1. **经济数据发布日**: CPI/PPI/PMI/GDP/社融/外贸(每月固定时间)
2. **行业景气跟踪**: 汽车产销/地产销售/钢铁产量/发电量(月度/周度)
3. **政策落地影响**: 新规实施后的数据变化(如电车国标→产销数据)
4. **A 股行情解读**: 指数/行业板块异动 + 资金流向数据
5. **消费民生**: 物价/就业/工资/社保数据

**筛选标准**:
- 有官方数据可获取(避免纯定性话题)
- 与"钱包/生计"强相关
- 可做历史对比(纵向)或行业对比(横向)
- 避开高风险政治/军事/民族/群体事件话题

#### B. 数据护城河建设
**积累维度**:
1. **时间序列**: 关键指标的月度/季度历史数据(至少 2-3 年)
2. **横向对比**: 同一时期不同行业/地区/国家数据
3. **关联指标**: 上下游/产业链/相关市场数据
4. **预期 vs 实际**: 机构预测 vs 实际公布(做预期差分析)

**例子**(新能源汽车):
- 月度产销(2021-2026)
- 渗透率变化曲线
- 充电桩/电池产能配套数据
- 政策时间轴(补贴退坡/国标实施)
- A 股新能源板块指数

#### C. 内容结构模板(签名框架)

**财经数据解读型**(650-750 字):

```
【钩子】(50-80 字,1-2 段)
- 第一句:反常识数字或反差("5 月新能源车销量占比首次破 56%,传统燃油车真的只剩 4 成了")
- 第二段:快速点出"这和读者的关系"(购车/投资/就业)

【数据呈现】(200-250 字,2-3 段)
- 核心数据 + 同比/环比/历史对比
- 用 1-2 个小表格或列表呈现关键数字
- 每个数据必带来源("据中汽协""国家统计局公布")

【解读分析】(200-250 字,2-3 段)
- 数据背后的驱动因素(政策/成本/技术/消费习惯)
- 横向对比(与其他行业/国家)
- 拆解主要矛盾(供给侧 vs 需求侧,短期 vs 长期)

【影响推演】(100-150 字,1-2 段)
- 对产业链(上游电池/下游充电桩)的影响
- 对消费者(购车成本/保值率/使用体验)的影响
- 对投资(相关板块/个股)的影响

【明确判断】(50-80 字,1 段)
- 给出清晰结论,不模棱两可
- 可以是"继续看多""谨慎观望""拐点已现"等
- 结尾留一个思考点或反问,不要求转发点赞
```

**正反对照**:

❌ **复述型(差)**
```
据新华网报道,7 月 1 日起两项强制性国标正式实施。
中汽协数据显示,5 月新能源汽车产销分别完成 155.4 万辆和 149.6 万辆。
专家表示,新国标将提升行业门槛...
```
→ 全是别处已有信息,无增量

✅ **数据解读型(好)**
```
5 月新能源车销量占比 56.9%,首次突破"油电五五开"。
更值得关注的是:过去 12 个月,这个数字从 38% 跳到 57%,
平均每月抬升 1.6 个百分点——加速度还在提高。

[小表格:近 6 个月渗透率变化]
2025-12: 48.2%
2026-01: 49.7%
...
2026-05: 56.9%

拐点出现在今年 3 月(首破 50%),背后是三重驱动...
```
→ 有独家整合的数据对比 + 自己的拆解

#### D. 每天 1 篇工作流
```
前一晚 22:00  → 确定明日选题(经济日历/热点事件)

```

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| AKShare 等免费源不稳定 | 多源冗余(Tushare/统计局);关键数据本地缓存 |
| LLM 编造数据 | 强制 prompt"只用提供数据";生成后自动校验数字来源 |
| 数据解读仍被判低创作度 | 确保"对比/趋势/推演"是自己整合的,非单一来源 |
| 每天 1 篇,涨粉慢 | 质量换留存率;用"数据日历"做系列,培养阅读习惯 |
| 全自动难保证质量 | Phase 1-2 可加轻量人工浏览(1-2 分钟),Phase 3 后再全自动 |
